# frontend — reserved

This directory is reserved for the site's client side. It holds no code and no configuration on
purpose: the project has not been started yet.

The stack is decided in [ADR-0004](../docs/adr/0004-nextjs-app-router-and-fsd-frontend.md): Next.js
with the App Router, TypeScript, Tailwind CSS, shadcn/ui, and Feature-Sliced Design in a pnpm
monorepo. The directory layout and all quality gates are documented in the Frontend section of
[`.dsh/AGENTS.md`](../.dsh/AGENTS.md).
