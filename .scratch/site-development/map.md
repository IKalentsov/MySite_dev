# Карта: сайт MySite

Type: wayfinder:map
Status: open

## Destination

Сайт работает целиком локально, end-to-end: реальный контент на русском и английском лежит в
PostgreSQL, одна публичная страница на Next.js читает его через API и показывает, всё
поднимается командами из `WORKFLOW.md`, бэкенд покрыт тестами, фронтенд проходит свои гейты.

Публикация — домен, хостинг, деплой — вне этой карты: владелец отложил её отдельным решением
(«пока что мы всё делаем локально»).

Назначение считается достигнутым, когда тикет 07 (тексты владельца) тоже закрыт: до него
страница показывает заглушки, а не реальный контент.

## Notes

**Этот effort несёт исполнение.** Отклонение от умолчания скилла `wayfinder` («планировать, а не
делать»): тикеты типа `task` здесь не только снимают блокировку с решения, но и делают работу —
иначе карта кончается пачкой решений без сайта. Тикеты `research` / `grilling` остаются
решениями.

**Скиллы, к которым обращаться в тикетах.**

- Бэкенд: `dotnet-webapi`, `tdd`, `karpathy-guidelines`, `optimizing-ef-core-queries`,
  `create-datadriven-aspnetcore`.
- Фронтенд: `vercel-react-best-practices`, `vercel-composition-patterns`, `better-accessibility`,
  `better-layout`, `better-typography`, `better-colors`, `better-ui`, `better-writing`,
  `web-design-guidelines`, `tdd`.
- Планирование и документы: `grilling`, `domain-modeling`, `research`, `architecture-drift-check`,
  `writing-guidelines`.

**Стоячие правила проекта.**

- Команды берутся из `WORKFLOW.md`, а не из памяти: `dotnet build MySite.slnx` (в песочнице
  `-m:1`), `dotnet test MySite.slnx` только из `backend/`.
- Билд чистый: `TreatWarningsAsErrors` + четыре анализатора. Анализатор не глушится — сначала
  чинится код, потом решение владельца с записью в реестр `WORKFLOW.md`.
- Версии пинуются точно и ровно в одном месте (`Directory.Packages.props` для бэкенда, корневой
  `package.json` для фронтенда).
- Решение, которое дорого откатить, удивляет без контекста и выбрано из реальных альтернатив,
  оформляется ADR в `docs/adr/`.
- Документы проекта ведутся на английском (`ARCHITECTURE.md`, ADR, `CONTEXT.md`), эта карта — на
  русском: она рабочий артефакт, не документация проекта.
- `.scratch/` не закрыт `.gitignore`, то есть карта уезжает в репозиторий. Так и задумано.

- [09 — Стек фронтенда и точные версии](issues/09-frontend-stack-and-versions.md): пины `next`
  16.4.0, `react`/`react-dom` 19.3.0, **`typescript` 6.0.3** (не `latest` 7.0.2 —
  `typescript-eslint` держит `<6.1.0`), `tailwindcss` 4.3.3, `eslint` 10.12.0; `transpilePackages`
  не нужен; тёмная тема = `@custom-variant dark` + `next-themes` с `attribute="class"`.
  Доказательства: `docs/research/frontend-stack-versions.md`.
- [17 — Где пинуются версии](issues/17-where-versions-are-pinned.md): pnpm-каталог в
  `pnpm-workspace.yaml`, пакеты ссылаются `"catalog:"`; правило в `.dsh/AGENTS.md` переписано;
  версия pnpm — через `devEngines.packageManager`, пол по Node — через `engines`; ADR не нужен.

Решения, принятые при разметке карты и записанные прямо здесь:

- **Назначение** — локальный end-to-end сайт; публикация вне карты. Подтверждено владельцем.
- **Содержание первой версии** — «обо мне» + проекты + контакт-заглушка (Telegram, почта).
- **Портал (игры, статьи, туториалы) сейчас не закладывается.** Модель остаётся под «обо мне» +
  проекты; новый раздел — будущая миграция.
- **Фронтенд — полная pnpm-монорепа** по `.dsh/AGENTS.md`: `apps/web`,
  `packages/{ui,api-client,shared,eslint-config,tsconfig}`. Это не отклонение от правил, а
  следование им.
- **Дизайн** — минимальная типографика и токены; референсы владельца приходят этапом полировки.
- **Тесты** — начинаем с архитектурных фитнес-функций и юнита на правило локали.
- **CI** — GitHub Actions, build + test бэкенда.
- **Identity-стек удаляется целиком** (тикет 01). Это отмена части ADR-0003 и требует нового ADR
  (тикет 02).

## Not yet specified

Туман: вопросы видны, но ещё не сформулированы так, чтобы стать тикетом.

- **Визуальный язык.** Референсы владельца: палитра, шкала типографики, тёмная тема как продукт,
  а не как базовая заготовка Tailwind.
- **Портал.** Статьи, туториалы, бест-практисы, игры: что первое, нужна ли общая модель
  «материала» с markdown, есть ли у материалов даты, теги и слаги.
- **Контактная форма.** `CONTEXT.md` уже определяет посетителя через форму: хранение сообщений,
  антиспам, куда приходит уведомление. Заглушка-ссылки её не заменяет навсегда.
- **Админка.** Экраны, модель контента, вход — отдельная карта после этой.
- **Публикация.** Домен, где живут Next.js, API и PostgreSQL, HTTPS, стоимость, CI/CD.
- **Английская версия как настоящая.** Кто переводит, что видит посетитель на месте отсутствующего
  перевода (правило fallback записано в ADR-0005, но не проверено на живых данных).
- **Аналитика.** Нужна ли вообще и в каком виде.

## Out of scope

Сознательно за пределами этой карты. Не graduates: вернуться можно только новой картой.

- Публикация, домен, хостинг, деплой. Причина: решение владельца «пока всё локально».
- Контактная форма с сохранением сообщений. Причина: заглушка из ссылок достаточна для локальной
  версии, форма — отдельная фича с таблицей и антиспамом.
- Админка. Причина: отдельная карта после публичной части.
- Статьи, игры, портал. Причина: владелец выбрал «рост не закладываем».
- Языки сверх `ru` и `en`.
